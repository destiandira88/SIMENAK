4.6.6 Penggunaan Program

Setelah proses instalasi selesai, Sistem Informasi Pemesanan pada Percetakan Z’Plack Berbasis Web (SIMENAK) dapat diakses dan digunakan sesuai kebutuhan masing-masing pengguna. Berikut dijelaskan panduan penggunaan program berdasarkan fitur-fitur utama yang tersedia pada sistem.

1. Halaman Landing Page

Halaman landing page merupakan halaman publik yang ditampilkan saat pengguna pertama kali membuka alamat sistem. Halaman ini menampilkan informasi layanan percetakan Z’Plack, katalog singkat, serta tombol untuk masuk dan mendaftar. Untuk mengakses halaman ini, pengguna membuka URL sistem melalui peramban web tanpa perlu login terlebih dahulu.

[Screenshot: Landing Page SIMENAK]

Gambar 4.35 Halaman Landing Page

2. Form Login Pelanggan

Form login pelanggan berfungsi untuk memasukkan kredensial akun agar pengguna dapat masuk ke sistem sesuai hak akses pelanggan. Form ini muncul dalam bentuk modal pada halaman landing ketika pengguna menekan tombol Masuk, kemudian mengisi email dan password, atau memilih opsi masuk dengan Google apabila fitur OAuth telah dikonfigurasi. Setelah login berhasil, sistem mengarahkan pengguna ke dashboard pelanggan.

[Screenshot: Modal Login Pelanggan]

Gambar 4.36 Form Login Pelanggan

3. Form Registrasi Pelanggan

Form registrasi pelanggan berfungsi untuk membuat akun baru dengan skema perseorangan agar pengguna dapat melakukan pemesanan. Untuk mengakses form ini, pengguna menekan tombol Daftar pada halaman landing, lalu mengisi data nama, email, nomor telepon, alamat, dan password. Setelah registrasi berhasil, pengguna diarahkan untuk login sebelum mulai menggunakan fitur pemesanan.

[Screenshot: Modal Registrasi]

Gambar 4.37 Form Registrasi Pelanggan

4. Portal Login Staff

Portal login staff berfungsi sebagai jalur masuk khusus untuk akun internal (admin, keuangan, produksi, dan owner). Halaman ini diakses melalui URL /login, kemudian pengguna mengisi email dan password sesuai akun staff. Setelah berhasil, sistem mengarahkan pengguna ke dashboard sesuai role masing-masing.

[Screenshot: Portal Login /login]

Gambar 4.38 Portal Login Staff

5. Dashboard Pelanggan

Dashboard pelanggan merupakan halaman utama setelah pelanggan berhasil login dan menampilkan ringkasan aktivitas pesanan serta akses cepat ke katalog dan pesanan. Untuk mengaksesnya, pelanggan login melalui modal landing page, lalu sistem menampilkan beranda pelanggan dengan navigasi horizontal di bagian atas.

[Screenshot: Dashboard Pelanggan]

Gambar 4.39 Dashboard Pelanggan

6. Halaman Katalog (Pelanggan)

Halaman katalog berfungsi untuk menampilkan daftar produk percetakan yang aktif beserta informasi harga, minimum order, dan estimasi pengerjaan. Untuk mengakses halaman ini, pelanggan memilih menu Katalog pada navigasi atas, kemudian dapat membuka detail produk dan menekan tombol pesan untuk membuat pesanan.

[Screenshot: Katalog Pelanggan]

Gambar 4.40 Halaman Katalog Pelanggan

7. Form Pemesanan

Form pemesanan berfungsi untuk mencatat data pesanan produk, termasuk jumlah, spesifikasi (form dinamis/EAV bila tersedia), metode pengiriman, serta opsi pesanan custom bila diperlukan. Untuk mengakses form ini, pelanggan membuka detail produk pada katalog lalu menekan tombol pesan, mengisi data yang diminta, dan mengirimkan pesanan. Pesanan yang berhasil dibuat akan muncul pada menu Pesanan Saya.

[Screenshot: Form Buat Pesanan]

Gambar 4.41 Form Pemesanan

8. Halaman Pesanan Saya

Halaman Pesanan Saya berfungsi untuk menampilkan daftar seluruh pesanan pelanggan beserta status terkini. Untuk mengaksesnya, pelanggan memilih menu Pesanan Saya pada navigasi atas, lalu dapat membuka detail pesanan untuk mengunggah bukti pembayaran, mereview draft desain, melakukan tracking, atau mengonfirmasi penerimaan.

[Screenshot: Pesanan Saya]

Gambar 4.42 Halaman Pesanan Saya

9. Form Upload Bukti DP

Form upload bukti DP berfungsi agar pelanggan dapat mengunggah bukti transfer uang muka pada pesanan yang mewajibkan DP. Fitur ini tersedia pada halaman detail pesanan ketika status pesanan menunggu verifikasi DP; pelanggan memilih file bukti (JPG/PNG/PDF, maksimal 2MB) lalu mengirimkannya untuk diverifikasi bagian keuangan.

[Screenshot: Upload Bukti DP]

Gambar 4.43 Form Upload Bukti DP

10. Halaman Review dan Revisi Desain (Pelanggan)

Halaman review desain berfungsi agar pelanggan dapat melihat draft desain yang diunggah bagian produksi, kemudian menyetujui (ACC) atau mengajukan revisi sesuai sisa kuota. Untuk mengaksesnya, pelanggan membuka detail pesanan yang berstatus proses desain, meninjau draft, lalu menekan tombol ACC atau Tolak disertai catatan revisi. Apabila sisa kuota habis, tombol tolak dinonaktifkan dan pelanggan hanya dapat memilih ACC.

[Screenshot: ACC / Revisi Desain]

Gambar 4.44 Halaman Review dan Revisi Desain

11. Form Upload Bukti Pelunasan

Form upload bukti pelunasan berfungsi untuk mengunggah bukti pembayaran sisa tagihan sesuai skema pesanan. Pada pelanggan perseorangan, form muncul saat status siap kirim atau siap diambil; pada kerja sama perusahaan, form muncul setelah barang diterima atau diambil (status menunggu verifikasi pelunasan). Pelanggan mengunggah file bukti dari halaman detail pesanan, kemudian menunggu verifikasi keuangan.

[Screenshot: Upload Bukti Pelunasan]

Gambar 4.45 Form Upload Bukti Pelunasan

12. Halaman Tracking Pemesanan

Halaman tracking pemesanan berfungsi menampilkan riwayat perubahan status pesanan secara kronologis agar pelanggan dapat memantau progres produksi hingga pengiriman. Untuk mengaksesnya, pelanggan membuka Pesanan Saya, memilih salah satu pesanan, lalu menekan tombol Tracking pada detail pesanan.

[Screenshot: Tracking Pemesanan]

Gambar 4.46 Halaman Tracking Pemesanan

13. Dashboard Admin

Dashboard admin merupakan halaman beranda role admin yang menampilkan ringkasan operasional pesanan dan akses menu pengelolaan. Setelah login melalui Portal Login dengan akun admin, pengguna diarahkan ke beranda dengan sidebar kiri berisi menu List Pemesanan, Katalog, Pengguna, Pengiriman, dan Laporan.

[Screenshot: Dashboard Admin]

Gambar 4.47 Dashboard Admin

14. Halaman List Pemesanan (Admin)

Halaman List Pemesanan berfungsi untuk menampilkan dan mengelola seluruh data pesanan, termasuk konfirmasi harga pada pesanan custom. Untuk mengaksesnya, admin memilih menu List Pemesanan pada sidebar, lalu membuka detail pesanan untuk menetapkan harga custom, memantau status, atau menindaklanjuti alur operasional.

[Screenshot: List Pemesanan]

Gambar 4.48 Halaman List Pemesanan

15. Halaman Kelola Katalog

Halaman kelola katalog berfungsi untuk menambah, mengubah, mengaktifkan, atau menonaktifkan produk percetakan serta mengatur template form spesifikasi per produk. Untuk mengaksesnya, admin atau owner memilih menu Katalog pada sidebar, kemudian dapat menambah produk baru atau mengelola field form dinamis sesuai kebutuhan produk.

[Screenshot: Kelola Katalog]

Gambar 4.49 Halaman Kelola Katalog

16. Halaman Manajemen Pengguna

Halaman manajemen pengguna berfungsi untuk mengelola akun pengguna, termasuk menetapkan atau mencabut status kerja sama perusahaan pada pelanggan. Untuk mengaksesnya, admin atau owner memilih menu Pengguna pada sidebar, lalu membuka detail pelanggan untuk mengisi data perusahaan dan dokumen pendukung bila menetapkan kerja sama.

[Screenshot: Manajemen Pengguna / Kerja Sama]

Gambar 4.50 Halaman Manajemen Pengguna

17. Halaman Manajemen Pengiriman

Halaman manajemen pengiriman berfungsi untuk memproses pesanan yang sudah siap dikirim atau diambil, termasuk menetapkan status siap, menginput nomor resi, serta mengonfirmasi pengambilan. Untuk mengaksesnya, admin memilih menu Pengiriman pada sidebar, memilih pesanan yang memenuhi syarat, lalu mengisi resi (metode kurir) atau menekan konfirmasi diambil (metode ambil sendiri).

[Screenshot: Manajemen Pengiriman]

Gambar 4.51 Halaman Manajemen Pengiriman

18. Dashboard Keuangan

Dashboard keuangan merupakan halaman beranda bagian keuangan yang menampilkan ringkasan pembayaran yang menunggu verifikasi. Setelah login melalui Portal Login dengan akun keuangan, pengguna diarahkan ke beranda dengan sidebar berisi menu Verifikasi DP, Verifikasi Pelunasan, Riwayat Pembayaran, dan Laporan Transaksi.

[Screenshot: Dashboard Keuangan]

Gambar 4.52 Dashboard Keuangan

19. Halaman Verifikasi DP

Halaman verifikasi DP berfungsi untuk meninjau bukti transfer uang muka yang diunggah pelanggan, kemudian menyetujui atau menolak bukti tersebut. Untuk mengaksesnya, bagian keuangan memilih menu Verifikasi DP pada sidebar, membuka bukti pembayaran, lalu menekan ACC atau Tolak disertai alasan bila ditolak.

[Screenshot: Verifikasi DP]

Gambar 4.53 Halaman Verifikasi DP

20. Halaman Verifikasi Pelunasan

Halaman verifikasi pelunasan berfungsi untuk memverifikasi bukti pembayaran pelunasan agar status pesanan dapat berlanjut sesuai skema (pelunasan terverifikasi atau selesai). Untuk mengaksesnya, bagian keuangan memilih menu Verifikasi Pelunasan pada sidebar, memeriksa bukti, lalu menyetujui atau menolak pembayaran.

[Screenshot: Verifikasi Pelunasan]

Gambar 4.54 Halaman Verifikasi Pelunasan

21. Halaman Riwayat Pembayaran

Halaman riwayat pembayaran berfungsi untuk menampilkan seluruh catatan transaksi DP dan pelunasan yang telah tercatat di sistem. Untuk mengaksesnya, bagian keuangan atau owner memilih menu Riwayat Pembayaran pada sidebar, lalu dapat memfilter data sesuai kebutuhan pemantauan.

[Screenshot: Riwayat Pembayaran]

Gambar 4.55 Halaman Riwayat Pembayaran

22. Dashboard Produksi

Dashboard produksi merupakan halaman beranda bagian produksi yang menampilkan ringkasan antrian desain dan pekerjaan terkait. Setelah login melalui Portal Login dengan akun produksi, pengguna diarahkan ke beranda dengan sidebar berisi menu Antrian Desain dan Manajemen Desain.

[Screenshot: Dashboard Produksi]

Gambar 4.56 Dashboard Produksi

23. Halaman Antrian Desain

Halaman antrian desain berfungsi untuk menampilkan daftar pesanan yang memerlukan pengerjaan desain serta status tahapannya. Untuk mengaksesnya, bagian produksi memilih menu Antrian Desain pada sidebar, lalu membuka detail pesanan untuk mengunggah draft atau memperbarui status produksi (misalnya menuju finishing).

[Screenshot: Antrian Desain]

Gambar 4.57 Halaman Antrian Desain

24. Halaman Manajemen Desain (Upload Draft)

Halaman manajemen desain berfungsi untuk mengunggah file draft desain pesanan agar dapat direview pelanggan. Untuk mengaksesnya, bagian produksi memilih menu Manajemen Desain atau membuka detail dari antrian desain, lalu mengunggah file draft (JPG/PNG, maksimal 1MB) beserta catatan produksi bila diperlukan.

[Screenshot: Upload Draft Desain]

Gambar 4.58 Halaman Manajemen Desain

25. Dashboard Owner

Dashboard owner merupakan halaman beranda pemilik usaha yang menampilkan ringkasan kinerja bisnis dan akses pemantauan menyeluruh. Setelah login melalui Portal Login dengan akun owner, pengguna diarahkan ke beranda dengan sidebar berisi menu pesanan, katalog, pengguna, pengiriman, riwayat pembayaran, riwayat aktivitas, manajemen desain, dan laporan.

[Screenshot: Dashboard Owner]

Gambar 4.59 Dashboard Owner

26. Halaman Laporan

Halaman laporan berfungsi untuk menampilkan rekap operasional dan bisnis, meliputi ringkasan bisnis, pemesanan, transaksi, serta desain. Untuk mengaksesnya, owner membuka menu Laporan pada sidebar lalu memilih submenu yang diinginkan; admin dapat membuka laporan pemesanan, sedangkan keuangan membuka laporan transaksi sesuai menu role masing-masing.

[Screenshot: Salah satu halaman Laporan]

Gambar 4.60 Halaman Laporan

27. Halaman Riwayat Aktivitas

Halaman riwayat aktivitas berfungsi untuk menampilkan jejak aktivitas internal sistem sebagai audit trail bagi owner. Untuk mengaksesnya, owner memilih menu Riwayat Aktivitas pada sidebar, lalu dapat memfilter log berdasarkan modul, aksi, atau rentang waktu.

[Screenshot: Riwayat Aktivitas]

Gambar 4.61 Halaman Riwayat Aktivitas

28. Halaman Profil Pengguna

Halaman profil berfungsi agar pengguna dapat melihat dan memperbarui data akun, seperti nama, nomor telepon, alamat, serta mengganti password. Untuk mengaksesnya, pengguna menekan menu profil atau ikon akun pada bagian atas halaman (navigasi pelanggan maupun topbar staff), lalu menyimpan perubahan yang diperlukan.

[Screenshot: Halaman Profil]
